# Pure Python: Syllabus

The course moves from understanding individual expressions to designing and building small programs. Work through the modules in order; use the linked [Module 1 notes](02-notes.md) and [Module 1 exercise](03-exercises.md) to begin.

## Module 1 — Think in Python

**Status:** In progress

**Goal:** Understand what the interpreter does with simple code and learn to inspect the values a program uses.

1. Start and use the Python REPL; distinguish an interactive session from a saved script.
2. Recognize values and basic types: `int`, `float`, `str`, and `bool`.
3. Create names with assignment and inspect the values they refer to.
4. Evaluate expressions and use the result to answer a small question.
5. Practice explaining the difference between a value, its type, a name, and an expression.

**Practice:** Complete [Exercise 1: A study-session record](03-exercises.md#exercise-1-a-study-session-record).
