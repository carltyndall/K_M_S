# `&`

Computes bitwise AND for integers; types such as sets may define intersection. In patterns it is not an alternative-pattern separator.

```python
6 & 3  # 2
```

See [`&=`](ampersand_equal.md), [`|`](pipe.md), and [binary bitwise operations](https://docs.python.org/3/reference/expressions.html#binary-bitwise-operations).
