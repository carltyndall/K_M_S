# `^=`

Augmented assignment applies bitwise XOR (or a type-defined operation), potentially in place, then assigns the result back.

```python
x = 6
x ^= 3  # x is 5
```

See [`^`](caret.md) and [augmented assignment](https://docs.python.org/3/reference/simple_stmts.html#augmented-assignment-statements).
