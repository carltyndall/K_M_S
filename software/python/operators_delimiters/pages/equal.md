# `=`

Separates assignment targets from values and appears in keyword arguments, parameter defaults, and debug formatted-string fields. It is not an equality comparison.

```python
x = 2
f'{x=}'  # 'x=2'
```

See [`==`](equal_equal.md), [`:=`](walrus.md), and [assignment statements](https://docs.python.org/3/reference/simple_stmts.html#assignment-statements).
