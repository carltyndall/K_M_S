# `{`

Opens a dictionary or set display; braces also delimit replacement fields in formatted strings and template strings.

```python
{'x': 1}
f'{2 + 3}'  # '5'
```

See [`}`](right_brace.md), [dictionary displays](https://docs.python.org/3/reference/expressions.html#dictionary-displays), and [formatted strings](https://docs.python.org/3/reference/lexical_analysis.html#f-strings).
