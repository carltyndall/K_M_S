# Git: Command Reference

Quick-reference cheat sheet for everyday Git operations.

| Command | Action |
| :--- | :--- |
| `git status` | Show current branch and staged/unstaged changes |
| `git diff` | View unstaged changes in working tree |
| `git log --oneline -n 5` | View last 5 commits in concise single-line format |
| `git add <file>` | Stage file for next commit |
| `git commit -m "<msg>"` | Create permanent snapshot with message |
