# `...`

The ellipsis literal evaluates to the singleton `Ellipsis`; it is not a general-purpose placeholder operator, though libraries may assign it meaning in subscriptions.

```python
... is Ellipsis  # True
```

See [literals](https://docs.python.org/3/reference/expressions.html#atom-literals) and [operators and delimiters](https://docs.python.org/3/reference/lexical_analysis.html#operators-and-delimiters).
