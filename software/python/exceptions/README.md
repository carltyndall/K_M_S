# Python built-in exceptions: alphabetical index

This reference covers the exception classes and compatibility aliases in the [Python 3 built-in exceptions documentation](https://docs.python.org/3/library/exceptions.html), including warning categories and exception groups. The documentation consulted describes Python 3.15; some entries are unavailable in older versions or on some platforms. See the [grouped index](01-grouped-index.md).

Exception classes form a hierarchy: catching a base class also catches its subclasses. Prefer specific exceptions; `BaseException` also includes termination and interruption signals. See [exception handling](../02-core-concepts.md) and the official [exception hierarchy](https://docs.python.org/3/library/exceptions.html#exception-hierarchy).
