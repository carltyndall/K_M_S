# `**`

Raises a value to a power; in calls and displays it unpacks mappings, and in parameters it collects extra keyword arguments.

```python
2 ** 3             # 8
{**{'x': 1}}       # {'x': 1}
def f(**kw): return kw
```

See [`*`](star.md), [`**=`](double_star_equal.md), and [the power operator](https://docs.python.org/3/reference/expressions.html#the-power-operator).
