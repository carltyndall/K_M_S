# Return statement

A return exits the current function with a value, or `None` if omitted. A `finally` clause executes before control actually leaves. A generator's return value is carried by `StopIteration`.

```python
def double(x):
    return 2 * x
```

See [`return`](../../keywords/pages/return.md). [Python documentation](https://docs.python.org/3/reference/simple_stmts.html#the-return-statement)
