# `:`

Separates a compound statement header from its suite, dictionary keys from values, slice bounds, annotations, and format specifications.

```python
{'x': 1}
[0, 1, 2][1:]
```

See [`:=`](walrus.md), [`;`](semicolon.md), and [slicings](https://docs.python.org/3/reference/expressions.html#slicings).
