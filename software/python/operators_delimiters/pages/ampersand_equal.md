# `&=`

Augmented assignment applies bitwise AND (or a type-defined operation such as set intersection), potentially in place, then assigns the result back.

```python
x = 6
x &= 3  # x is 2
```

See [`&`](ampersand.md) and [augmented assignment](https://docs.python.org/3/reference/simple_stmts.html#augmented-assignment-statements).
