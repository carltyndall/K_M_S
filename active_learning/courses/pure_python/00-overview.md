# Pure Python: Overview

## Why Another Python Course

### Primary Reasons (Goals)

* The course focuses on learning how to program using Python, not just learning Python syntax.
* The course includes foundational programming concepts that most Python courses overlook.
* The course emphasizes Pure Python.

### Supporting Reasons (Objectives)

* The course builds a knowledge management process to help learners retain and apply what they learn.
* The course integrates artificial intelligence as a learning tool for Python programming.
* The course is designed for beginners and intermediate learners, with a clear path for growth.
* The course explains the expected lifespan of the material and how to keep skills current.
* The course teaches and follows a structured learning process.
* The course develops a reproducible programming workflow.
* The course is designed specifically for Windows 11, the operating system most learners actually use.

## Prerequisites

No programming experience is required. Learners should be comfortable using a computer, opening a terminal or Python editor, and saving files in a known location. The examples use Python's built-in language and standard library; no third-party packages are required.

## Learning Outcomes

By the end of the course, learners should be able to:

* Explain how Python evaluates simple programs and how values, names, types, and expressions fit together.
* Break a small problem into steps and express those steps as readable Python code.
* Use core language features, including control flow, collections, functions, and basic file operations, to build small programs.
* Run, inspect, test, and debug a program using a repeatable workflow on Windows 11.
* Record useful learning in the course workspace and promote durable concepts or tool knowledge to the appropriate K_M_S layer.
* Use AI to ask focused questions, generate practice, and review reasoning while checking suggestions by running and explaining the code.

## Course and Knowledge-Management Placement

This directory is the active course trail: syllabus, lesson synthesis, and exercises belong here. Daily notes are the intake log; move durable programming mental models to [`concepts/`](../../../concepts/README.md) and reusable Python tool or reference material to [`software/python/`](../../../software/python/README.md). Link to those references instead of copying them wholesale into the course.

## Course Vision

This course is about more than Python. It's about learning how to think, learn, solve problems, and build software.
