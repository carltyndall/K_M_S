# `(`

Opens a parenthesized expression, tuple display, call, or parameter list. A comma, not parentheses alone, generally makes a tuple.

```python
(1 + 2)  # 3
tuple([1, 2])
```

See [`)`](right_paren.md), [parenthesized forms](https://docs.python.org/3/reference/expressions.html#parenthesized-forms), and [calls](https://docs.python.org/3/reference/expressions.html#calls).
