# `**=`

Augmented assignment raises the target to the power of the right operand, potentially in place, then assigns the result back.

```python
x = 3
x **= 2  # x is 9
```

See [`**`](double_star.md) and [augmented assignment](https://docs.python.org/3/reference/simple_stmts.html#augmented-assignment-statements).
