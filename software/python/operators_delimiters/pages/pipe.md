# `|`

Computes bitwise OR or an operation defined by the operands, such as set or dictionary union. It also forms type unions and separates alternatives in patterns.

```python
1 | 2       # 3
int | str   # union type
```

See [`|=`](pipe_equal.md), [bitwise operations](https://docs.python.org/3/reference/expressions.html#binary-bitwise-operations), and [OR patterns](https://docs.python.org/3/reference/compound_stmts.html#or-patterns).
