# bytearray

Create a mutable sequence of bytes from an iterable, size, buffer, or encoded string.

**Signature:** `bytearray(source=b'', encoding=None, errors='strict')`

```python
bytearray([65, 66])  # bytearray(b'AB')
```

[Python documentation](https://docs.python.org/3/builtins/functions.html#func-bytearray)
