# `@`

Performs matrix multiplication on supporting types; at the start of a decorator line it introduces a decorator.

```python
@staticmethod
def f(): pass
```

See [`@=`](at_equal.md), [binary arithmetic](https://docs.python.org/3/reference/expressions.html#binary-arithmetic-operations), and [function definitions](https://docs.python.org/3/reference/compound_stmts.html#function-definitions).
