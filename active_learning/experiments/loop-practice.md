# Loop practice

Try this example in a Python environment:

```python
numbers = [1, 2, 3]
total = 0
for number in numbers:
    total = total + number
print(total)  # 6
```

Before running it, predict the output. Then try an empty list and explain why the result is zero. See the [daily observation](../daily_notes/2026-11-24-daily-notes.md), [general concept](../../concepts/loops.md), and [Python note](../../software/python-loops.md).
