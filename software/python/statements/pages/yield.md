# Yield statement

A yield statement is a yield expression without surrounding parentheses. It suspends a generator rather than terminating it.

```python
def once():
    yield 1
```

See [`yield`](../../keywords/pages/yield.md) and [yield expressions](../../expressions/pages/yield-expressions.md). [Python documentation](https://docs.python.org/3/reference/simple_stmts.html#the-yield-statement)
