# `/`

Performs true division. In function parameter lists, it also marks preceding parameters as positional-only.

```python
5 / 2  # 2.5
def f(x, /): return x
```

See [`//`](double_slash.md), [`/=`](slash_equal.md), and [function definitions](https://docs.python.org/3/reference/compound_stmts.html#function-definitions).
