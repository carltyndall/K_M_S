# `!`

Introduces a conversion such as `!r`, `!s`, or `!a` in a formatted or template string replacement field. It is not a standalone logical NOT operator; use `not`.

```python
f'{"x"!r}'  # "'x'"
```

See [`!=`](not_equal.md) and [formatted string literals](https://docs.python.org/3/reference/lexical_analysis.html#f-strings).
